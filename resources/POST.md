Content-type:	
	- Test
		- html -> página HTML
		- css -> pagina css
		- plain -> texto puro
		- etc
	
	- Application
		- application/json                  → JSON
		- application/xml                   → XML
		- application/x-www-form-urlencoded → formulário simples
		- application/octet-stream          → binário genérico
		- application/pdf                   → PDF

	- Imagem:
		- image/jpeg  → JPG
		- image/png   → PNG
		- image/gif   → GIF
		- image/webp  → WEBP
		- image/svg+xml → SVG
	
	- Multipart:
		- multipart/form-data; boundary=----ABC  → upload de ficheiros
		- multipart/byteranges                   → download parcial
